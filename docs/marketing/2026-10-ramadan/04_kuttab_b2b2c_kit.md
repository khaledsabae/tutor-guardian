# الكتاتيب والحضانات والمدارس (B2B2C مجاني)

> العلامات ⏳ معرّفة في [`00_README.md`](00_README.md).
> **القرار الحاكم:** لرمضان ١٤٤٨ نعمل بـ**النسخة صفر** (رابط وكود لكل مؤسسة، يعمل بمجرد إنشاء الأكواد — بوابة G0).
> **كود الفصل ⏳ F-CLASS** مواصفة فقط، ومقترح شحنه **للعام الدراسي سبتمبر 2027**، لا قبل رمضان.
> السبب: المرحلة ٢ محمّلة أصلًا (رحلة الصلاة، برنامج رمضان، تكافؤ الإنجليزية) وبوابتها ١٥ يناير؛ إضافة ميزة جديدة لها
> واجهة معلّم وواجهة أهل تهدد البوابة. البديل المرفوض: بناء F-CLASS في ديسمبر — أعلى أثرًا لو نجح، لكنه يراهن بالبرنامج كله.

## ١. صفحة التعريف (للطباعة أو الإرسال كصورة) — عربي

```
المربّي — رفيق مجاني لأسر طلابكم

ما هو؟
تطبيق «المربّي» يساعد الأب والأم في تربية أبنائهم خطوةً بخطوة: دروس قصيرة لكل عمر، ونصيحة يومية،
ومساعد يجيب عن أسئلتهم التربوية. مجاني بالكامل لوجه الله: بلا إعلانات ولا اشتراكات ولا ميزة مقفلة.

ماذا تكسب أسر طلابكم في رمضان؟ [⏳ F-RAMADAN]
برنامج رمضان للأسرة، ثلاثون يومًا: تحدٍّ عائلي صغير كل يوم، وتدريب الطفل على الصيام بالتدريج بحسب سنّه،
وورد قرآن للأسرة، وقصة قبل النوم. ما يتعلّمه الطفل عندكم في الكُتّاب يجد امتدادًا له في البيت.

ماذا يفعل المعلّم؟ (عشر دقائق مرة واحدة)
١. يرسل رسالة جاهزة في جروب أولياء الأمور.
٢. يعلّق ملصقًا فيه رمز QR عند المدخل.
٣. هذا كل شيء.

ماذا يعرف المعلّم بعد ذلك؟
كل شهر تصلكم رسالة بعدد الأسر التي انضمّت من رابطكم، وعدد من بقي منها يستعمل التطبيق بعد أسبوعه الأول.
أرقام فقط: لا أسماء، ولا بيانات أي أسرة أو طفل.

الخصوصية
لا نطلب من المؤسسة أي بيانات عن الطلاب أو الأهل. الأسرة تبدأ بلا حساب ولا بريد إلكتروني،
واسم الطفل يُحذف من أي سؤال قبل إرساله إلى الذكاء الاصطناعي.

التكلفة
لا شيء. لا الآن ولا لاحقًا.

ملاحظة: التطبيق على أندرويد حاليًا.
للتواصل: [وسيلة تواصل خالد]
```

> **قبل G2** (شحن البرنامج وتجربته) يُحذف قسم «ماذا تكسب أسر طلابكم في رمضان؟» بالكامل، وتبقى الصفحة صحيحة بدونه.
> بلا شعار المؤسسة على المطبوعة دون إذن مكتوب منها. وبلا أي نص شرعي (README §٢).

## ٢. مسار المعلّم

### النسخة صفر — متاحة بعد G0 (لا تحتاج أي بناء)

| الخطوة | من | ماذا |
|---|---|---|
| 1 | خالد | يعطي المؤسسة كودًا `KT01`… (السجل في ملاحظاته المحلية: الكود ↔ المؤسسة) |
| 2 | خالد | يرسل للمعلّم: صفحة التعريف أعلاه + رسالة جروب الأهل أدناه + ملصق A4 فيه QR إلى `https://tg-api.alsaba.cloud/go?ref=KT01` |
| 3 | المعلّم | يرسل الرسالة في جروب الأهل، ويعلّق الملصق |
| 4 | الأهل | يثبّتون التطبيق من الرابط؛ التطبيق يعمل كالمعتاد (لا ميزات فصل) |
| 5 | خالد | أول كل شهر: يشغّل استعلام README §٣ لكود المؤسسة ويرسل للمعلّم **رقمين مجمّعين** (انضموا / نشطوا في الأيام ٧–١٤). إن كان العدد أقل من ٥ يكتب «أقل من ٥» |
| 6 | المعلّم (رمضان) ⏳ F-RAMADAN | يعيد توجيه بطاقة تحدّي اليوم من قناة واتساب إلى جروب الأهل إن أحب |

**رسالة جروب الأهل (يرسلها المعلّم):**
```
السلام عليكم أولياء الأمور الكرام،
ننصحكم بتطبيق «المربّي»: مساعد مجاني للأهل في تربية الأبناء، فيه دروس قصيرة لكل عمر ونصيحة يومية،
[⏳ F-RAMADAN: وفيه برنامج لرمضان للأسرة ثلاثين يومًا، وتدريب للطفل على الصيام بحسب سنّه].
مجاني بالكامل، بلا إعلانات (أندرويد):
https://tg-api.alsaba.cloud/go?ref=[KT01]
```

**نص الملصق (A4):** «المربّي — رفيقكم في تربية الأبناء» · QR كبير · «مجاني لوجه الله · أندرويد» · بلا صور أطفال.

### النسخة الأولى — مع كود الفصل ⏳ F-CLASS

| الخطوة | من | ماذا |
|---|---|---|
| 1 | المعلّم | في التطبيق: «المزيد ← أنا معلّم/ة ← أنشئ فصلًا» — اسم الفصل (مثل «حلقة الفجر»)، نوع المؤسسة، الفئة العمرية (اختياري)، البرنامج (مثل رمضان) |
| 2 | التطبيق | يعطيه كودًا من ٦ خانات + رابطًا + QR + رسالة جاهزة للجروب |
| 3 | الأهل | يفتحون الرابط أو يكتبون الكود في «الإعدادات ← انضم إلى فصل»، أو يُلتقط الكود تلقائيًا عند التثبيت من الرابط |
| 4 | الأهل | يرون بطاقة صغيرة «أنت في: حلقة الفجر» ورسالة المعلّم الأسبوعية (من قوالب جاهزة) |
| 5 | المعلّم | يرى لوحة: عدد الأسر، ونسبة النشطين هذا الأسبوع، و⏳ F-RAMADAN نسبة من أنجز تحدّي اليوم — **فقط إن كان الأعضاء ٥ فأكثر** |
| 6 | الأهل | «غادر الفصل» بضغطة واحدة في أي وقت |

## ٣. مواصفة «كود الفصل» ⏳ F-CLASS (غير مبنية — مواصفة فقط)

### الأهداف وما ليس هدفًا

- **الهدف:** مؤسسة واحدة تُدخل عشرات الأسر دفعة واحدة، وتبقيها، ويرى المعلّم أثرًا مجمّعًا يحفزه على الاستمرار.
- **ليس هدفًا:** محادثة بين الأهل، أو بين المعلّم وولي أمر بعينه، أو أي نص حرّ يحتاج إشرافًا (الخطة: «لا مجتمع ولا منتديات»
  — الإشراف مستحيل لشخص واحد)، أو رؤية المعلّم لأي أسرة بعينها.

### نموذج البيانات (إضافي بالكامل — `CREATE TABLE IF NOT EXISTS`؛ رقم المخطط يحدده المنسّق)

```sql
CREATE TABLE IF NOT EXISTS classes (
    id               INTEGER PRIMARY KEY AUTOINCREMENT,
    code             TEXT NOT NULL UNIQUE,        -- 6 خانات من أبجدية بلا 0/O/1/I (نفس _ALPHABET في referral.py)
    owner_device_id  TEXT NOT NULL,               -- جهاز المعلّم؛ لا حسابات
    name             TEXT NOT NULL,               -- ≤ 40 حرفًا، تُحذف منه الروابط والأرقام الطويلة
    org_type         TEXT NOT NULL,               -- kuttab | nursery | school | weekend_school | masjid | other
    age_group        TEXT,                        -- اختياري: أحد الفئات الثماني
    program_id       TEXT,                        -- مثل 'ramadan_1448'؛ NULL = بلا برنامج
    lang             TEXT NOT NULL DEFAULT 'ar',  -- لغة قوالب رسالة المعلّم
    created_at       TEXT NOT NULL DEFAULT (datetime('now')),
    archived_at      TEXT                         -- يؤرشف تلقائيًا بعد نهاية البرنامج بـ30 يومًا
);
CREATE INDEX IF NOT EXISTS ix_classes_owner ON classes (owner_device_id);

CREATE TABLE IF NOT EXISTS class_members (
    class_id   INTEGER NOT NULL,
    device_id  TEXT NOT NULL,
    joined_at  TEXT NOT NULL DEFAULT (datetime('now')),
    via        TEXT NOT NULL DEFAULT 'code',      -- code | link | install_referrer
    PRIMARY KEY (class_id, device_id)
);
CREATE INDEX IF NOT EXISTS ix_class_members_device ON class_members (device_id);

CREATE TABLE IF NOT EXISTS class_notes (          -- رسالة المعلّم الأسبوعية: من قوالب فقط
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    class_id     INTEGER NOT NULL,
    template_id  TEXT NOT NULL,                   -- مفتاح ARB، لا نص حرّ
    created_at   TEXT NOT NULL DEFAULT (datetime('now'))
);
```

**لا جدول أحداث جديد:** نشاط الأعضاء يُحسب من الجداول الموجودة (`lesson_progress`، `chat_sessions/chat_messages`، وجدول
تقدّم برنامج رمضان حين يُبنى) بالربط على `device_id` — نفس تعريف «النشط» في `weekly_funnel_report.py` ومؤشر النجم الشمالي.
**لا يُربط الفصل بالطفل:** العضوية على مستوى الجهاز (الأسرة)، فلا يحتاج الخادم أن يعرف أي طفل في أي فصل.

### الواجهات (إضافية؛ النسخ القديمة لا تتأثر)

| الطريقة | المسار | من | يعيد |
|---|---|---|---|
| POST | `/api/classes` | المعلّم (Bearer) | `{id, code, share_url, qr_payload}`؛ حد ٣ فصول/جهاز/يوم |
| GET | `/api/classes/{code}/preview` | عام | `{name, org_type, program_id}` فقط — لعرض «ستنضم إلى: حلقة الفجر» قبل التأكيد |
| POST | `/api/classes/{code}/join` | ولي الأمر (Bearer) | `{ok, class: {...}}`؛ متكرر بلا أثر؛ حد ٣٠ محاولة/IP/ساعة ضد التخمين |
| DELETE | `/api/classes/{code}/membership` | ولي الأمر | `{ok}` — يحذف الصف فعلًا لا يعلّمه |
| GET | `/api/classes/mine` | الطرفان | فصولي (معلّمًا) وفصولي (عضوًا) |
| GET | `/api/classes/{id}/summary` | المالك فقط | `{members, active_week_pct, program_today_pct}` — **`null` لكل نسبة إن كان الأعضاء < 5** |
| POST | `/api/classes/{id}/notes` | المالك فقط | `{template_id}` من قائمة ثابتة؛ حد رسالة/أسبوع |
| GET | `/c/{code}` | عام (ويب) | صفحة هبوط عربية/إنجليزية: «انضم إلى [اسم الفصل] على المربّي» + زر Play بـ`referrer=cls_<CODE>` |

**الالتقاط عند التثبيت:** يضاف بجوار `REF_([A-Z0-9]{4,16})` في `referral_service.dart` نمط `CLS_([A-Z0-9]{6})`؛ إن وُجد يُعرض
على الأب «هل تريد الانضمام إلى [اسم الفصل]؟» — **لا انضمام صامت**. يتطلب نسخة تطبيق جديدة؛ النسخ القديمة تتجاهل `cls_` بلا ضرر.

### الخصوصية (وجودية هنا)

1. **المعلّم لا يرى أي أسرة بعينها** — لا أسماء، ولا أجهزة، ولا من انضم متى. أرقام مجمّعة فقط.
2. **عتبة ٥:** أي نسبة على فصل أقل من ٥ أعضاء تُعاد `null` من الخادم (لا يكفي إخفاؤها في الواجهة) — فصل من عضوين يكشف أسرة.
3. **الانضمام بموافقة صريحة** بعد رؤية اسم الفصل؛ والمغادرة بضغطة.
4. **لا ربط بالأطفال**؛ واسم الطفل لا يمر بهذه الواجهات إطلاقًا.
5. **الحذف:** المغادرة تحذف صف العضوية. أرشفة الفصل (تلقائيًا بعد ٣٠ يومًا من نهاية البرنامج) ثم حذف صفوف أعضائه بعد ٩٠ يومًا.
   ⚠️ **لا يوجد اليوم مسار «احذف كل بياناتي» على مستوى الجهاز** (README §٤)؛ حين يُبنى يجب أن يشمل `class_members` وفصول المالك.
6. **سياسة الخصوصية** (`docs/privacy-policy.md`) تُحدَّث قبل الشحن: بيان جديد = «عضوية فصل» و«فصول أنشأتها».
7. **رسالة المعلّم من قوالب فقط** (مفاتيح ARB بالعربية والإنجليزية): «تذكير بتحدّي هذا الأسبوع»، «بارك الله في أسركم»، «بقي أسبوع على رمضان»… — لا نص حرّ، فلا إشراف لازم ولا خطر روابط أو أرقام.

### الفئات العمرية

الفصل له فئة اختيارية للعرض فقط. **المحتوى يتبع طفل كل أسرة لا الفصل:** أسرة في «حلقة ٧–٩» وطفلها في ٤–٦ ترى برنامج ٤–٦.
إن كان البرنامج (رمضان) لا يغطي فئة ما، ترى الأسرة المسار العائلي العام للبرنامج إن وُجد — يحدده تصميم ⏳ F-RAMADAN لا هذه المواصفة.

### ما يُقاس

| المؤشر | التعريف | الهدف الأول |
|---|---|---|
| فصول نشطة | فصل فيه ≥ ٥ أعضاء وعضو نشط هذا الأسبوع | ٢٠ في أول برنامج |
| أعضاء/فصل | الوسيط | ≥ ١٥ |
| بقاء أعضاء الفصول | D7 لأعضاء الفصول مقابل غيرهم (نفس تعريف التقرير الأسبوعي) | أعلى من غير الأعضاء بفارق ملحوظ — وإلا فالميزة توزيع لا احتفاظ |

### التستات المطلوبة عند البناء

- إنشاء فصل → كود فريد من الأبجدية الصحيحة؛ الحد اليومي.
- `preview` لا يعيد إلا الحقول الثلاثة.
- `join` متكرر بلا أثر؛ كود خاطئ 404؛ حد المحاولات.
- `summary` لغير المالك 403؛ ولأقل من ٥ أعضاء كل النسب `null` **من الخادم**.
- `notes` يرفض أي `template_id` خارج القائمة.
- المغادرة تحذف الصف؛ والأرشفة والحذف المؤجل.
- الموبايل: الانضمام والمغادرة على المحاكي بالعربية والإنجليزية، داكن، ونص ٢٠٠٪، ثم الخروج وإعادة الفتح.

### قرارات مع البديل المرفوض

| القرار | البديل المرفوض | لماذا |
|---|---|---|
| عضوية على مستوى الأسرة (الجهاز) | عضوية لكل طفل | لا يحتاج الخادم معرفة أي طفل في أي فصل؛ أقل بيانات = أقل خطر |
| قوالب فقط لرسالة المعلّم | نص حرّ / محادثة | الإشراف مستحيل لشخص واحد، والخطة ترفض المجتمعات المفتوحة |
| عتبة ٥ في الخادم | إخفاء في الواجهة | الواجهة يمكن تجاوزها؛ الخصوصية تُفرض حيث تُحسب |
| تأجيل إلى سبتمبر 2027 | قبل رمضان | يحمي بوابة ١٥ يناير؛ والنسخة صفر تقيس الطلب الحقيقي أولًا: إن لم تجلب الأكواد `KT` أسرًا في رمضان، فلا داعي لبناء الميزة |
